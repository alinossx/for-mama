# Маленький — сайт под песню

## Что нужно положить в папку:

1. **music.mp3** — песня «Маленький» (Дайте танк !)
2. **mama1.jpg** — фото мамы (появляется на словах «мама опять сильнее всех в мире»)
3. **mama2.jpg** — второе фото мамы (в самом конце)

## Как пользоваться:

1. Открой `index.html` или залей на GitHub Pages
2. Нажми кнопку **«начать»**
3. Смотри анимацию под музыку

## Тайминги можно подкрутить

В файле `index.html` найди массив `timeline` и меняй цифры (секунды от начала песни).
