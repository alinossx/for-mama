# Мама, я тебя люблю

Трогательный визуальный эдит под песню «Маленький» группы Дайте танк (!)

## Как запустить

1. Положи свои 15 детских фото в папку `images/` с именами:
   - photo1.jpg
   - photo2.jpg
   - ...
   - photo15.jpg

2. Положи аудиофайл в папку `audio/` с именем:
   - daitetank-malenkiy.mp3

3. Залей весь этот архив на GitHub и включи GitHub Pages.

Готово.
